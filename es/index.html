Cómo funciona.

CONVERSIÓN DE EDAD

H = rC + BC · e−C/3 · (1 − C/Cmax)

r = 3.22165 se calcula a partir de récords mundiales de longevidad. B = 10.8519 representa la maduración temprana.

Es una analogía, no un modelo médico validado. La alternativa es H = rC.
